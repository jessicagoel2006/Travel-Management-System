# ✈️Travel Management System built using C++ and OOP concepts

A console-based Travel Management System developed using C++ and Object-Oriented Programming (OOP) concepts. The project helps users organize trips by managing traveler details, transportation, accommodation, and travel itineraries through an interactive menu-driven interface.

---

# 📌 Project Overview

The Travel Management System is designed to simplify trip planning and management. Users can enter travel details, select transportation options, choose accommodation preferences, and generate a complete trip itinerary.

This project was developed as part of academic learning to strengthen understanding of C++ programming and OOP principles.

---

# 🚀 Features

- Add and manage traveler information
- Select mode of transportation
- Manage accommodation details
- Generate trip itinerary
- Interactive menu-driven interface
- User-friendly console output
- Organized travel planning workflow
